## Purpose

This repository serves as a learning archive documenting progress and exercises completed during the course.

It is intended for portfolio viewing and educational reference only.

## Contents

Examples of topics covered:

* React components
* Props & state
* Event handling
* Lists & rendering
* Forms
* Basic hooks
* Small UI exercises

Each folder represents a separate small task or exercise.
